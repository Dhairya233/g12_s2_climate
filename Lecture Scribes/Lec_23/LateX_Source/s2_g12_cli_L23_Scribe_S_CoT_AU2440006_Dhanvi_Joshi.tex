\section{Tail Bounds Introduced}

The lecture introduces three fundamental tools:

\begin{itemize}
\item Markov's Inequality
\item Chebyshev's Inequality
\item Chernoff Bound
\end{itemize}

These are used to bound probabilities of extreme deviations.

\section{Markov's Inequality}

\subsection{Assumptions}

\begin{itemize}
\item $X \ge 0$ (non-negative random variable)
\item $a > 0$
\end{itemize}

\subsection{Definition}

\[
P(X \ge a) \le \frac{\mathbb{E}[X]}{a}
\]

\subsection{Step-by-Step Reasoning}

\begin{enumerate}
\item Consider non-negative random variable $X$
\item Focus on probability $P(X \ge a)$
\item Use expectation $\mathbb{E}[X]$
\item Since $X \ge a$ contributes at least $a$:
\[
\mathbb{E}[X] \ge a \cdot P(X \ge a)
\]
\item Rearranging:
\[
P(X \ge a) \le \frac{\mathbb{E}[X]}{a}
\]
\end{enumerate}

\subsection{Conclusion}

Provides an upper bound using only expectation.

\section{Chebyshev's Inequality}

\subsection{Assumptions}

Random variable $X$ with:

\begin{itemize}
\item Mean $\mu$
\item Variance $\sigma^2$
\end{itemize}

\subsection{Definition}

\[
P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}
\]

\subsection{Step-by-Step Reasoning}

\begin{enumerate}
\item Consider deviation $|X - \mu|$
\item Square both sides:
\[
(X - \mu)^2 \ge k^2 \sigma^2
\]
\item Apply Markov's inequality:
\[
P((X - \mu)^2 \ge k^2 \sigma^2)
\le \frac{\mathbb{E}[(X - \mu)^2]}{k^2 \sigma^2}
\]
\item Use:
\[
\mathbb{E}[(X - \mu)^2] = \sigma^2
\]
\item Substitute:
\[
P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}
\]
\end{enumerate}

\subsection{Conclusion}

Improves over Markov by incorporating variance.

\section{Chernoff Bound}

\subsection{Purpose}

Provides tighter (exponentially decreasing) bounds.

\subsection{General Form}

\[
P(X \ge (1+\delta)\mu) \le e^{-f(\delta,\mu)}
\]

\subsection{Step-by-Step Reasoning}

\begin{enumerate}
\item Start with:
\[
P(X \ge a)
\]
\item Apply exponential transformation:
\[
P(e^{tX} \ge e^{ta})
\]
\item Apply Markov's inequality:
\[
P(e^{tX} \ge e^{ta}) \le \frac{\mathbb{E}[e^{tX}]}{e^{ta}}
\]
\item Choose parameter $t$ to minimize the bound
\item Result yields exponential decay
\end{enumerate}

\subsection{Conclusion}

\begin{itemize}
\item Strongest among the three bounds
\item Useful for rare event analysis
\end{itemize}
