\section*{$\Rightarrow$ Hierarchy of Bounds (Information vs Accuracy)}

Markov → Mean $(\mu)$  

Chebyshev → Mean + Variance  

Chernoff → Full distribution (MGF)  

\vspace{0.2cm}

\textbf{Reasoning:}

\begin{enumerate}
\item More input → tighter bound
\item Less input → looser bound
\end{enumerate}

\vspace{0.6cm}

%----------------------------------

\section*{$\Rightarrow$ Markov Inequality}

\[
P(X \ge a) \le \frac{\mu}{a}
\]

\vspace{0.2cm}

Uses only mean  

Decay: $1/k$ (linear)  

Exact $\approx 0.004$  

Markov $\approx 0.714$  

\vspace{0.2cm}

\textbf{Conclusion:}

Very loose bound  

``Wastes space''  

\vspace{0.6cm}

%----------------------------------

\section*{$\Rightarrow$ Chebyshev Inequality}

\[
P(X \ge a) \le \frac{\sigma^2}{(a-\mu)^2}
\]

\vspace{0.2cm}

Uses variance (captures spread)  

Decay: $1/k^2$  

Exact $\approx 0.004$  

Chebyshev $\approx 0.125$  

\vspace{0.2cm}

\textbf{Conclusion:}

Tighter than Markov  

Still overestimates  

\vspace{0.6cm}

%----------------------------------

\section*{$\Rightarrow$ Chernoff Bound}

\[
P(X \ge a) \le \min_{t>0} e^{-ta} M_X(t)
\]

\vspace{0.2cm}

Uses full distribution (MGF)  

Includes optimization over $t$  

Fastest decay (exponential)  

Closest to exact tail  

\vspace{0.2cm}

\textbf{Conclusion:}

Tightest bound  

Best approximation  

\vspace{0.6cm}

%----------------------------------

\section*{$\Rightarrow$ Decay Comparison}

Markov → Linear $(1/k)$  

Chebyshev → Polynomial $(1/k^2)$  

Chernoff → Exponential  

\vspace{0.6cm}
